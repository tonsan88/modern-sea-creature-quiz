# 現代の海の生き物診断 🌊

<div align="center">
  <img src="./docs/Web_Portfolio_SeaCreatureQuiz.png" alt="現代の海の生き物診断 制作実績" width="720">

12の質問から性格傾向を分析し、15種類の海の生き物にたとえて結果を表示するWeb診断です。
「笑えて、ちょっと当たる」をテーマに、診断結果を読むだけでも少し前向きになれる体験を目指しました。

## 🔗 デモ

**[診断を試す](https://modern-sea-creature-quiz.day-to-day-developme.chatgpt.site)**

登録・ログイン不要、約2分で遊べます。

## ✨ 主な機能

- 3択×12問の性格診断
- 重み付けスコアによる15タイプ判定
- メインタイプと隠れたサブタイプの表示
- タイプごとの性格、強み、あるある、アドバイス、相性
- 15種類のオリジナル生き物イラスト
- Web Share APIによる診断結果の共有
- スマートフォン／PC対応のレスポンシブデザイン

## 🐠 診断タイプ

イルカ／鯛／ペンギン／カクレクマノミ／タコ／シャチ／クラゲ／ウミガメ／昆布／ホタテ／深海魚／ウミヘビ／クジラ／クリオネ／カニ

## 🛠 使用技術

- TypeScript
- React
- Next.js
- HTML / CSS
- Vinext / Vite
- Cloudflare Workers互換環境
- 生成AI：ChatGPT・Codex（企画、文章設計、画像制作支援、実装支援）

## 💡 工夫した点

- 15タイプが重複しすぎないよう、性格傾向と判定条件を個別設計
- 全回答パターン `3¹² = 531,441通り` を想定した決定的な判定処理
- 「否定しない・かわいい・クスッと笑える」文章トーンを全タイプで統一
- 結果を9つのセクションに分け、読み物としても楽しめる構成に設計
- 個人情報や回答を収集しない、端末内完結の診断処理

## 🔒 プライバシー

メールアドレス、氏名、回答、診断結果を取得・送信・保存する処理はありません。回答と判定結果はページを開いている間だけブラウザのメモリ上で扱われ、再読み込みすると消えます。

「結果をシェアする」を押した場合のみ、結果文とURLを端末の共有機能またはクリップボードへ渡します。アプリの運営者やサーバーへ送信するものではありません。

## 📌 制作について

本作品では、生成AI（ChatGPT・Codex）をアイデアの壁打ち、文章案・画像の制作、実装の補助に活用しました。

一方で、作品の企画と目的、全体仕様、15タイプの定義、12問の質問、判定方針は私自身が設計・決定しています。生成された提案はそのまま採用せず、タイプ間の重複や文章の読みやすさ、世界観との一貫性を確認したうえで、必要な内容を選定し、加筆・修正しました。

実装後も、全タイプの診断結果、画面表示、シェア機能、判定動作、個人情報を保存しない設計を自分で確認しています。生成AIに制作を一任したものではなく、企画・仕様決定から品質確認まで、制作責任者として判断しながら完成させた作品です。

実装・動作確認・公開まで、生成AIを活用しながら一連の制作工程を行っています。
